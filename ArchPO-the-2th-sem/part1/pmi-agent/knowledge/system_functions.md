# Функции системы ГОСТ 34 — справочник для тестирования

Перечень всех функций автоматизированной системы с кратким описанием.
Используй для точного именования функций в тест-плане и ПМИ.

---

## Auth Service (порт 8001) — Аутентификация и авторизация

| ID | Наименование функции | Описание |
|---|---|---|
| F-AUTH-01 | Регистрация пользователя | Создание учетной записи администратором организации |
| F-AUTH-02 | Аутентификация (вход) | Проверка логина/пароля, выдача JWT |
| F-AUTH-03 | Двухфакторная аутентификация (TOTP) | Проверка кода из приложения-аутентификатора |
| F-AUTH-04 | Выход из системы | Инвалидация сессии, отзыв токена |
| F-AUTH-05 | Смена пароля | Смена пароля с проверкой текущего |
| F-AUTH-06 | Сброс пароля | Восстановление доступа по email |
| F-AUTH-07 | Управление пользователями (admin) | Создание, изменение, деактивация пользователей своей организации |
| F-AUTH-08 | Управление проектами | Создание проектов, привязка организаций |
| F-AUTH-09 | RBAC — ролевое разграничение | Проверка прав при выполнении операций |
| F-AUTH-10 | Аудит действий | Журналирование всех операций с учетными данными |
| F-AUTH-11 | Обезличивание ПДн | Псевдонимизация при деактивации пользователя |
| F-AUTH-12 | Управление согласием на обработку ПДн | Запись и отзыв согласия пользователя |

---

## Catalog Service (порт 8002) — Справочник и шаблоны

| ID | Наименование функции | Описание |
|---|---|---|
| F-CAT-01 | Управление шаблонами документов | CRUD шаблонов (ТЗ, ЧТЗ, ПМИ, НМЦК) |
| F-CAT-02 | Управление функциями системы | CRUD справочника функций |
| F-CAT-03 | Управление подсистемами | CRUD структуры подсистем |
| F-CAT-04 | Управление ставками | CRUD трудоемкости функций (только РП) |
| F-CAT-05 | Управление документами | CRUD документов проекта |
| F-CAT-06 | Блокировка/разблокировка документов | Изменение статуса при согласовании (через Kafka) |
| F-CAT-07 | Render-bundle | Сборка полного пакета данных для генерации |
| F-CAT-08 | Мягкое удаление | Soft delete объектов с проверкой зависимостей |

---

## Generation Service (порт 8003) — Генерация документов

| ID | Наименование функции | Описание |
|---|---|---|
| F-GEN-01 | Генерация ТЗ (.docx) | Создание технического задания по ГОСТ 34.602 |
| F-GEN-02 | Генерация ЧТЗ (.docx) | Создание частного технического задания |
| F-GEN-03 | Генерация ПМИ (.docx) | Создание программы и методики испытаний |
| F-GEN-04 | Генерация НМЦК (.xlsx) | Расчет начальной максимальной цены контракта |
| F-GEN-05 | Хранение файлов (MinIO) | Загрузка и скачивание сгенерированных документов |

---

## Workflow Service (порт 8004) — Согласование

| ID | Наименование функции | Описание |
|---|---|---|
| F-WF-01 | Создание запроса на согласование | Отправка документа на согласование РП |
| F-WF-02 | Принятие решения (РП) | Утверждение / отклонение / запрос доработки |
| F-WF-03 | Многораундовое согласование | Автоматическое создание нового раунда при «доработке» |
| F-WF-04 | Отмена согласования | Отмена активного запроса (ПМ, admin) |
| F-WF-05 | Дашборд согласований | Просмотр статусов всех согласований проекта |
| F-WF-06 | Задачи РП | Список документов, ожидающих решения |
| F-WF-07 | История согласований | Полная история раундов и решений |
