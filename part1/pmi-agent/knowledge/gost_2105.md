# ГОСТ 2.105-2019 — Требования к оформлению документов

## Назначение

ГОСТ 2.105-2019 устанавливает общие требования к текстовым документам, включая документы автоматизированных систем.
При генерации .docx файлов в системе ГОСТ 34 используются стили, соответствующие этому стандарту.

---

## Общие требования к оформлению

| Параметр | Значение |
|---|---|
| Формат бумаги | A4 (210 × 297 мм) |
| Ориентация | Книжная (допускается альбомная для таблиц) |
| Шрифт | Times New Roman, 14 пт |
| Межстрочный интервал | 1,5 |
| Поля | Левое: 30 мм, Правое: 10 мм, Верхнее: 20 мм, Нижнее: 20 мм |
| Нумерация страниц | Арабские цифры, снизу по центру |
| Абзацный отступ | 15 мм |

---

## Стили, используемые в шаблоне системы (.dotx)

Имена стилей в файле `gost-2105-template.dotx`:

| Семантический элемент | Имя стиля в шаблоне |
|---|---|
| Обычный текст | `ph_normal` |
| Заголовок 1 уровня | `heading 1` |
| Заголовок 2 уровня | `heading 2` |
| Заголовок 3 уровня | `heading 3` |
| Элемент маркированного списка (1 ур.) | `ph_list_itemized_1` |
| Элемент маркированного списка (2 ур.) | `ph_list_itemized_2` |
| Элемент нумерованного списка (1 ур.) | `ph_list_enumerated_1` |
| Элемент нумерованного списка (2 ур.) | `ph_list_enumerated_2` |
| Подпись к рисунку | `ph_caption_figure` |
| Подпись к таблице | `ph_caption_table` |
| Содержимое таблицы | `ph_table_body` |
| Заголовок таблицы | `ph_table_header` |

## Требования к таблицам (п. 4.4 ГОСТ 2.105)

1. Таблицы нумеруются арабскими цифрами в пределах раздела
2. Наименование таблицы — над таблицей: «Таблица N — Наименование»
3. Заголовки граф — с прописной буквы
4. Единицы измерения указываются в заголовке графы
5. При переносе таблицы — повторять заголовок или добавить «Продолжение таблицы N»

---

## Требования к рисункам (п. 4.3 ГОСТ 2.105)

1. Рисунки нумеруются в пределах раздела
2. Подпись: «Рисунок N — Наименование» (под рисунком)
3. Ссылка в тексте: «(рисунок 1)» или «приведен на рисунке 1»

## Что проверяет тестировщик при генерации документа

При испытании F-GEN-03 (генерация ПМИ .docx):

1. Файл открывается без ошибок
2. Стили соответствуют приведенной таблице выше
3. Заголовки разделов используют стили `heading 1`, `heading 2`
4. Основной текст использует стиль `ph_normal`
5. Таблицы используют стили `ph_table_header`, `ph_table_body`
6. Поля и шрифт соответствуют требованиям
7. Нумерация страниц присутствует
